# Common/

- The art here is generated: change `tools/derive_art.py` and rerun it (`python -I tools/derive_art.py`; `--check` compares), never hand-edit a file it writes. It reads byte copies of the vanilla files it needs from `tools/seed/vanilla/`, vendored locally and gitignored (refresh with `--vendor <Assets.zip>`), and `python -I tools/check_refs.py` checks every art path the pack's JSON names.
- The exception is the artist's hand-made Headless Horseman art, copied in as it came: `Items/Hallows_Eve/Horseman_Armor/` (the Horseman's armour, which the tool also reads for the rider's armour, the Breastplates' cut chest and the chase set's icons; its `Player/` holds the artist's exports of a piece made to fit a player, now the legs, which the chase set wears while the Horseman keeps his own) and `NPC/Hallows_Eve/Headless_Horseman/Horse/` (his black horse, which the tool also reads for the Steed Trophy block and the steed's icon). Replace those files with the artist's new exports, never edit them, then rerun the tool.

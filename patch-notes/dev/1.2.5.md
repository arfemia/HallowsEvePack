Seasons of Orbis 1.2.5 is a data hotfix cut from 1.2.4 for Harvest Feast's first live run (November 20 to December 1, 2026): one conversation fix, found auditing the feast forced on with and without MMO Skill Tree on Hytale 0.7.4. Manifest: `Version` 1.2.5 and the `Description`'s Harvest Feast dates; `ServerVersion`, `Dependencies` and `OptionalDependencies` unchanged. No lang key changes.

## Fixed

- `Dialogues/SeasonsOfOrbis/Harvest_Feast_Host.json`: the `Then` line `feast_done` reads `harvest_feast_the_feast` in `States` `COMPLETED` or `ON_COOLDOWN`, where it read `State` `COMPLETED` alone. A `Repeat.PerRun` quest reads `ON_COOLDOWN` once this run has paid it (it comes back next year), so Martha's after-feast line never showed and she fell back to her menu line. Old Jack's `lantern_lit` reads both states the same way.

## Changed

- The README and the store page describe Harvest Feast now that it runs: Martha's quests, dailies, board, shop, villagers, Wild Turkeys, favor and achievements, its MMO Skill Tree XP, and the Festival Shelf at each host's shop.
